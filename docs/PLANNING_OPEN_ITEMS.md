## A. 점수 값에 직접 영향 — 결정 필요

### A-1. 영역 가중치 — 환경 영역 처리 ★최우선

| | |
|---|---|
| 기획 | §7③ Phase 1 = 신체 30 · 정신 25 · 감정 20 · 사회 15 · **환경 10**. "환경은 날씨-맥락 placeholder, 실 환경신호 확보 전까지 중립 유지" |
| 문제 | 환경은 온보딩·일지 모두 입력이 없어 전원 동일한 상수 50점. 원안대로면 **종합점수 상한 95점 / 하한 5점**이 되고, 모든 사용자가 같은 5점 블록을 공유한다. 변별력 0인 항목이 나머지 4영역의 해상도를 10% 잠식 |
| 현재 구현 | 환경 가중치 0, 나머지 4개를 ÷0.90 재정규화 → 신체 .333 · 정신 .278 · 감정 .222 · 사회 .167 (**원안의 상대 비율은 보존**) |
| 결정 요청 | (a) 재정규화 유지 — 실 환경신호 확보 시 되돌림 / (b) 기획 원안대로 환경 10 복원 |

- 기획 §7③은 "결정 완료" 항목이므로 임의 변경 아님을 명시하고 승인 요청한다.

### A-2. 결측 영역의 분모 처리

| | |
|---|---|
| 기획 | §6 `Score = Σ W_c × C_c` — 5영역이 모두 존재한다는 전제로 나눗셈 없음 |
| 문제 | 사회 영역은 소스 2개(온보딩 Q11 · 일지 '사람 만남')가 **둘 다 화면 미반영**이라 현재 항상 결측(→ D-1). 그대로 합산하면 가중치 0.167이 소리 없이 사라져 만점이 83점이 됨 |
| 현재 구현 | 값이 없는 영역은 분자·분모 양쪽에서 제외 후 재정규화. 기획이 **항목 단위에서 이미 쓰는 규칙(§4 결측 재정규화)** 을 영역 단위로 동일 적용 |
| 결정 요청 | 이 해석 승인 여부 |

### A-3. 감정 영역 '기분 회복 활동' 앵커 부재

| | |
|---|---|
| 기획 | 일지 §3에서 **채점 항목**(방향 정)으로 분류. §B-2 `일지_감정 = avg(스트레스×k, 기분 회복 활동)` |
| 문제 | §8 정규화 기준표에 **이 항목의 행이 없음**. 확인 가능한 값은 §B-3 워크드 예시의 `잠깐 = 60` 한 점뿐 |
| 현재 구현 | 채점 제외. 감정 영역은 **스트레스 단일 소스**로 동작 |
| 결정 요청 | 선택지 3개 앵커 확정: `안 함 = ? · 잠깐 = 60 · 충분히 = ?` |

- 확정 시 감정 영역이 2소스가 되어 안정성이 올라간다(기획이 §6⑥에서 명시한 '감정 보강'의 목적).
- '사람 만남'(30/60/100)에서 값을 유추할 수 있으나 근거가 없어 적용하지 않았다.
- **실측 영향** — §B-3 예시를 실서버에서 재현한 결과, 감정 영역이 기획 예시보다 **10.6점 낮다**
  (구현 38.89 = 스트레스만 / 기획 49.5 = avg(스트레스 39, 기분회복 60)). 가중치 0.222 기준
  종합점수로는 약 2.4점 차이.

| 영역 | 기획 §B-3 | 구현 | |
|---|---|---|---|

### A-5. 7일 이동평균 적용 횟수

| 위치 | 내용 |
|---|---|
| 산출식 §1 (파이프라인) | ④baseline 결합 → ⑤가중합 → **⑥7일 이동평균** (별도 단계) |
| 산출식 §5 (결합식) | `C_c(t) = (1−α)·baseline_c + α·**mean7**(C_c)` — 결합식 **내부에 이미** mean7 |
| 산출식 §7 | "표시 종합점수 = 최근 7일 Score의 이동평균" |

- 결정 요청: 이 해석 승인 여부.

## B. 수식 미정으로 미구현 — 데이터는 이미 쌓이는 중

세 항목 모두 **"무엇을 한다"만 있고 "얼마나"가 없다.** 응답은 `dna_info`에 정상 저장되고 있으므로, 수치가 정해지면 소급 재계산 가능하다.

### B-1. 크로노타입(Q1) → 취침 채점 기준점 이동

- 기획 §6②: "아침형 22\~23시 · 저녁형 24\~01시 · 일반형 23\~24시 · **예민형 baseline 폭 축소**"
- 미정 ①: **예민형의 구간도 축소 계수도 없음** (4개 중 1개가 공란)
- 미정 ②: 세 유형의 시간대는 있으나, 그 창을 벗어났을 때 **감점 방식·감점량**이 없음
- 현재 구현: 수면시간을 크로노타입과 무관하게 이상구간 7\~9h · 밖 1h당 15점 감점(§8)으로 채점. **크로노타입은 점수에 전혀 반영되지 않음**
- 필요: 예민형 정의 + 기준점 이탈 시 감점 규칙

### B-2. 생활 리듬(Q10) → 취침·기상 규칙성 편차 채점

- 기획 일지 §4 매핑표: "생활 리듬(규칙성) ↔ 취침·기상 규칙성 → **규칙성 편차 채점**"
- 미정: 편차 산출 방식(표준편차? 중앙값 대비 절대편차?), 기간(7일?), 편차 → 점수 변환식 전부 없음
- 현재 구현: Q10은 **온보딩 baseline 점수로만** 사용(§A-1 매우 규칙=100 등). 일지의 실제 취침·기상 규칙성은 채점하지 않음
- 필요: 편차 정의 + 정규화식

### B-3. 근무 형태(Q7) → 수면 규칙성 기준 완화

- 기획 §3 Q7 역할: "리스크 플래그 → 수면 규칙성 완화", §1③ "감점보다 보정·표시용 플래그"
- 미정: **완화 폭이 없음**. B-2가 미정이라 완화할 대상 자체도 아직 없음
- 현재 구현: 플래그만 저장, 점수 미반영
- 필요: B-2 확정 후 완화 계수

## C. 문서 오류 — 수정 필요 (결정 아님)

### C-1. Q12 선택지 — 단일문항 vs WHO-5 5문항

- 기획 §3 문항표 Q12 선택지: `매우 낮음 / 낮음 / 보통 / 좋음 / 매우 좋음` **(단일 5점 척도)**
- 같은 칸 괄호: `(WHO-5 5문항 · 0~100)`
- 기획 §7⑤ (결정 완료): "**WHO-5 = 풀버전(5문항) 채택**. 0\~5 ×5 합산 ×4 → 0\~100. 단일문항 축약은 타당도를 잃어 부적절"
- 판단: **§7⑤가 최종**. §3 문항표의 선택지 칸이 축약안 시절 그대로 남아 있음
- 현재 구현: 5문항(`who5_q1`\~`q5`, 각 0\~5) · 합계×4 · 한 문항이라도 비면 결측 처리
- 요청: §3 문항표 Q12 선택지 칸 수정

### C-2. §A-4 워크드 예시의 '기분·활력 75' — 산출 불가능한 값

- WHO-5 5문항 환산은 `합(0~25) × 4` → **4의 배수만 가능**. 75는 나올 수 없음
- 원인: C-1과 동일. 단일 5점 척도(0/25/50/75/100) 시절의 예시가 남음
- 영향: §A-4의 day-0 = 80점 예시가 현행 5문항 기준으로는 재현되지 않음
- 요청: 예시를 4의 배수(예: 76)로 갱신 → 감정 baseline·종합점수 예시값도 함께 조정

### C-3. WHO-5 5개 문항 텍스트 부재

- 기획 어디에도 **실제 문항 5개의 문구가 없음**. §7⑤는 "풀버전 채택"만 명시
- 영향: 클라이언트가 Q12 화면을 그릴 수 없음. 서버는 문항 번호(`who5Q1`\~`Q5`)로만 저장 중
- 요청: WHO-5 표준 5문항 한국어 문구 확정(Topp 2015 표준본 기준)

## D. 화면 미반영으로 데이터가 안 쌓이는 항목

기획에는 **확정**돼 있으나 목업에 없다. 서버는 컬럼·검증 모두 준비돼 있어 화면만 추가되면 즉시 동작한다.

### D-1. 온보딩 (목업 `02_INITIAL_DIAGNOSIS`)

| 문항 | 기획 | 화면 | 결과 |
|---|---|---|---|
| Q11 사회 교류 | 확정 (Ⓑ 4점, Holt-Lunstad) | 없음 | **사회 baseline 소스 0개** |
| Q12 기분·활력(WHO-5) | 확정 (§7⑤) | 없음 | 감정 baseline이 생활리듬 1개로 축소 |

### D-2. 일지 (목업 `01_CREATE_DIARY`)

| 항목 | 기획 | 화면 | 결과 |
|---|---|---|---|
| 사람 만남 | 채점 확정 | 없음 | **사회 당일점수 소스 0개** |
| 카페인 잔 수 · 마지막 섭취 시각 | 채점 확정 | 없음 | 신체·정신에서 카페인 항목 결측 |
| 기분 회복 활동 | 채점 확정 | 없음 | A-3과 중복 |
| 걸은 시간 | 참고(비채점) | 없음 | 영향 없음 |

### D-3. 결과 — 사회 영역이 구조적으로 항상 결측

- D-1 Q11 + D-2 '사람 만남' = 사회 영역의 **소스 전부**
- 둘 다 없으므로 사회 영역은 baseline·당일점수 모두 산출 불가 → A-2의 재정규화가 없으면 전 사용자 점수가 왜곡됨
- 요청: 최소 **Q11(온보딩 1문항)** 만이라도 화면 추가 시 사회 baseline 확보 가능

## 부록 — 결정에 따라 재계산이 필요한 범위

- A-1 / A-2 / A-5 변경 시 → `daily_score` 전 행 재산출 필요
- A-3 / B-1\~B-3 확정 시 → 신규 소스 추가이므로 마찬가지로 재산출 필요
- 재산출은 원본(`dna_info` + `diary`)에서 항상 복원 가능하도록 설계돼 있음. 파라미터 변경 시 `scoring.version`을 올리면 각 행에 산출 기준이 기록되어 과거 점수와 섞이지 않음 (현재 `v1.0-coldstart`)
